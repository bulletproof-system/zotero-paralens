# ParaLens 测试样本

本目录保存可再分发的合成 PDF 和映射 fixture，不保存用户 Zotero 库、私有文档、凭据或真实翻译产物。

## 样本清单

| 文件                             | 内容和用途                                                                 | SHA-256                                                            |
| -------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `gui-smoke-short-en.pdf`         | 自行生成的单页英文样本，用于模拟翻译和原生 Reader 测试                     | `73d592fc465fde50a29fcd91481baf6d3159823b5e3a994b3e6f2856047e9aec` |
| `gui-smoke-two-pages-en.pdf`     | 自行生成的两页英文河流／海洋样本，有可选文本层，用于逐页映射和跨页导航测试 | `7b7c05b126dfc668b9f244fdd2f67b6d151a9641196d288d0ee9b15dd9dc0fd1` |
| `two-paragraphs.mapping.v1.json` | 两段可信几何的映射测试数据，用于双向命中和高亮切换                         | 测试用 PDF 摘要、附件 key 和时间是占位值，不对应真实用户附件       |

PDF 使用 `scripts/local-api-translation-smoke.py` 的合成生成逻辑，不含第三方论文内容。映射用于协议和几何测试，不代表任意真实 PDF 可获得相同覆盖率。

## 测试数据边界

- 本目录的合成样本不覆盖任意公式、表格、参考文献、扫描页、裁切或旋转组合。
- 单元测试中的几何数据及运行时生成的变体与真实论文质量验收不同。
- 测试输出放在 `.scaffold/` 或专用系统临时目录，不作为仓库输入数据保存。
- 使用其他 PDF 时，需核实来源和再分发权限；无法确认权限或含敏感内容的文档不应复制到仓库，也不记录可关联私人文档的文件名、路径或指纹。

测试模式和授权要求见[后端设置指南](../docs/backend-setup.md)。
